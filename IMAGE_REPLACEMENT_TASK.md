## 🛠️ Delivery Instructions for Graphic Designer

1. **File Format Priority:** Use **WebP** for photographic imagery, **SVG** for logos/badges, and **PNG** for transparent graphics.
2. **Optimization:** Compress all web images (maximum file size 250KB per photo, 15MB for MP4 video loop).
3. **Naming Convention:** Keep exact filenames or update references in `content/` files as specified above.
4. **Color Space:** sRGB for all web deliverables.
